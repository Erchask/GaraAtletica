GaraAtletica è un progetto Java che simula una gara podistica gestita tramite thread, dove ogni atleta corre in modo indipendente seguendo il proprio ritmo e subendo imprevisti generati casualmente. Durante la corsa gli atleti possono scivolare, distrarsi o avere bevuto qualcosa di sospetto che li rende insolitamente veloci, creando una gara caotica e imprevedibile. Il giudice si occupa di registrare gli atleti, impostare la lunghezza della gara, avviare simultaneamente i thread e controllare l’ordine di arrivo. Al termine della gara viene generata una classifica che può essere visualizzata e salvata su file tramite un gestore dedicato, così da mantenere traccia del risultato finale.
